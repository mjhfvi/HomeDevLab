# Update Kubernetes Cluster

This guide will show how to update the Kubernetes cluster with new services and applications, to ensure that the cluster remains up-to-date and can support the latest features and capabilities.

## Update Cluster with terragrant

you can run `terragrant apply` command to apply any changes to the cluster configuration, such as adding new services or updating existing ones.

clone the 'devops.cloud.infrastructure' repository and navigate to the 'terragrant' directory.
